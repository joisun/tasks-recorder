# Tasks 原生滚动渲染

用户授权：必要时允许重构为更合理的实现。范围仅 React Tasks 渲染层，不改 API、后台服务或 legacy dashboard。

## 第一性原理

目标：滚动流畅且 Tree/Timeline 同行对齐。事实：相同数据滚动触发 SVAR Grid init，13 次纵向事件对应 13 次初始化；阻断事件后流畅但破坏同步，不能作为产品修复。约束：保留选择、展开、状态操作、恢复、列宽调整、时间尺度、计划与执行分段。成功标准：真实滚动无长任务或明显帧间隔恶化，行坐标一致，操作测试与类型检查通过。

## Johari

Open：瓶颈已有 CDP 对照证据。Hidden：用户极限任务数量及触控硬件未知。Blind：替换渲染器可能损失键盘操作和日期边界准确性。Unknown：原生布局在真实数据上的 paint 成本，需同手势测量，不以删除同步换取性能。
